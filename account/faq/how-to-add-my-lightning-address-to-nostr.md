# How to add my lightning address to Nostr

You can now use your Alby lightning address to receive zaps on Nostr.&#x20;

{% hint style="info" %}
Nostr users can send bitcoin payments to each other using the bitcoin lightning network.
{% endhint %}

Many Nostr apps allow to edit your profile. \
After you logged into a Nostr app ([2-minute guide](https://blog.getalby.com/the-2-minute-alby-guide-to-nostr/)), you can add your lightning address to one of these sites:

* [https://iris.to/profile/edit](https://iris.to/profile/edit)
* [https://snort.social/settings/profile](https://snort.social/settings/profile)
* [https://coracle.social/profile](https://coracle.social/profile)
* [Damus](https://damus.io/) or [Amethyst](https://play.google.com/store/apps/details?id=com.vitorpamplona.amethyst\&hl=en\&gl=US) on mobile

You only have to add your lightning address once and every other app knows about it.\
\
**Congrats! You are now able to receive zaps. 👍**
