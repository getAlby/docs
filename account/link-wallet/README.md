# 🔗 Link wallet

Do you want to enhance your bitcoin lightning wallet with many cool [features](../features/)? Link it to an Alby Account! ✨

Alby accounts support wallets that implemented [NWC](https://nwc.dev/) - a simple, secure and open protocol to link wallets with apps.&#x20;
