### For Web Apps

At Alby we build on open standards. Alby exposes a number of javascript objects to the browser, which can be used to interact with bitcoin on-chain (WebBTC), bitcoin lightning (WebLN), Nostr, Liquid, and more.

{% content-ref url="https://app.gitbook.com/o/uiUeRqI074apbV0PWsyf/s/5v1D1WJg7nITCqn5NLQJ/" %}

### For Web and Mobile Apps

If you want to power your web or mobile app with bitcoin and want to offer payments directly in the app, have a look at the [Alby NWC Wallet API](https://app.gitbook.com/o/uiUeRqI074apbV0PWsyf/s/HyuCj8CH0AbFLyvhXAEx/). It allows native payment experiences for users. As a web and mobile developer, you can entirely focus on your app. Alby covers your back and does the payment processing for you.

Have a look at the Alby NWC Wallet API documentation:

{% content-ref url="https://app.gitbook.com/o/uiUeRqI074apbV0PWsyf/s/HyuCj8CH0AbFLyvhXAEx/" %}
[NWC Wallet API](https://app.gitbook.com/o/uiUeRqI074apbV0PWsyf/s/HyuCj8CH0AbFLyvhXAEx/)
{% endcontent-ref %}

### Alby Meta Tags

Customize the Alby experience and provide meta data to Alby interactions on your website.

#### Customize recipient meta data

```
<meta property="alby:name" content="[RECIPIENT NAME]" />
<meta property="alby:image" content="[IMAGE URL]" />
```
