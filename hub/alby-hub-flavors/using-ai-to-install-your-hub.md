# 🤖 Using AI to Install Your Hub

Ask your AI agent to help you install Alby Hub on Fly.io guide you through the installation with Alby Hub Skill.

**Copy this prompt and ask your agent:**

```
Use this skill: https://github.com/getAlby/hub-skill to install Alby Hub and guide me through the setup
For a new HTTP-server deployment, enable a random SETUP_CODE before the first start. If the installer generates one, preserve it. Tell me how to retrieve it privately to complete onboarding, and keep the Hub behind secure network access.
```

Find more information about the Alby Hub Skill on GitHub: [https://github.com/getAlby/hub-skill](https://github.com/getAlby/hub-skill)
