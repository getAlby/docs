# Where is Alby Hub physically located?

Alby Hub is a wallet with an embedded Lightning node, giving you full self-custody of your funds. Your wallet is secured by a 12-word recovery phrase known only to you.

You run Alby Hub yourself and host it wherever you prefer—at home, on a node device like Umbrel or Start9, or with a cloud provider of your choice. Because Alby Hub is self-custodial, only you control your keys no matter where it runs.

To send and receive payments, your Hub needs to be online, so we recommend hosting it on a device or server that stays online 24/7.
