# 👾 Features

#### With Alby Browser Extension, you can:

🧩 manage multiple Bitcoin Lightning wallets

🧩 use Bitcoin and Nostr apps on the web with the [Alby Browser Extension](https://getalby.com/alby-extension)

🧩 connect to your own node, [Alby Hub](https://getalby.com/alby-hub) or Alby Account

🧩 recover your Bitcoin or Nostr private key with a Master Key, a 12-word seed phrase
