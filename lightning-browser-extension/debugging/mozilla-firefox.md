# Mozilla Firefox

This section guides you to find the relevant data that helps us to debug the Alby browser extension.&#x20;

#### 1. Step: **Open 'about:debugging#/runtime/this-firefox' in your Firefox Browser**

![](<../.gitbook/assets/image (101).png>)

#### **2. Step: Locate the Alby browser extension in your list and click on 'Inspect'**

![](<../.gitbook/assets/image (97).png>)

#### **3. Step:** Navigate to “Console”. Are there any error messages? If yes, make a screenshot.

![](<../.gitbook/assets/image (103).png>)

#### 4. Step: Navigate to 'Network'. Are there any error messages in red? If yes, make a screenshot.

![](<../.gitbook/assets/image (88).png>)

#### 5. Step: **Please describe the issue and send your screenshots to** us via the chat widget on support.getalby.com
