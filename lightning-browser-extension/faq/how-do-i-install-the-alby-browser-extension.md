# How do I install the Alby Browser Extension?

You can always start from the [Alby Browser Extension page](https://getalby.com/alby-extension) and choose the version for your browser.

🖥️ Desktop: You can download and install the Alby Browser Extension for Chromium- and Firefox-based browsers, like [Google Chrome](https://chrome.google.com/webstore/detail/alby-bitcoin-lightning-wa/iokeahhehimjnekafflcihljlcjccdbe), [Brave](https://chrome.google.com/webstore/detail/alby-bitcoin-lightning-wa/iokeahhehimjnekafflcihljlcjccdbe), [Mozilla Firefox](https://addons.mozilla.org/en-US/firefox/addon/alby/), [Tor Browser](https://addons.mozilla.org/en-US/firefox/addon/alby/), [Microsoft Edge](https://github.com/getAlby/lightning-browser-extension#try-out-the-most-recent-version-of-alby-nightly-releases), [Opera](https://chrome.google.com/webstore/detail/alby-bitcoin-lightning-wa/iokeahhehimjnekafflcihljlcjccdbe).&#x20;

📱 Mobile: You can download and install the Alby Browser Extension for [Firefox on Android](https://addons.mozilla.org/en-US/firefox/addon/alby/).\
\
Download the Alby Extension to your browser! The installation will start automatically.\
\
Make sure to pin the extension to the browser bar after installation.
