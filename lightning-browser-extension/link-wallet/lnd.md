# LND

### Use Alby Hub to link your Umbrel to the Alby Browser Extension

#### **Step 1: Install Alby Hub**

{% content-ref url="https://app.gitbook.com/s/WIUBf3ZZaBGu2ee6Y8lU/alby-hub-flavors" %}
[Alby Hub flavors](https://app.gitbook.com/s/WIUBf3ZZaBGu2ee6Y8lU/alby-hub-flavors)
{% endcontent-ref %}

#### **Step 2: Connect your LND node to Alby Hub**

You just installed Alby Hub. Now start the app. During the onboarding&#x20;

1. select **“Advanced Setup”.**

<figure><img src="../.gitbook/assets/image (207).png" alt=""><figcaption></figcaption></figure>

2. Select **LND**
3. Choose an **unlock password**
4. Provide the required credentials (e.g. macaroon) to finalize the connection

#### **Step 3: Finish the setup of Alby Hub**

{% content-ref url="https://app.gitbook.com/s/WIUBf3ZZaBGu2ee6Y8lU/getting-started" %}
[Getting Started](https://app.gitbook.com/s/WIUBf3ZZaBGu2ee6Y8lU/getting-started)
{% endcontent-ref %}

#### **Step 4: Link Alby Hub powered by LND to the Alby Browser Extension**

Open Alby Hub → **Connections** → find and click on the **Alby Browser Extension** → click **“Connect to Alby Extension”** -> Follow the instructions.

{% content-ref url="https://app.gitbook.com/s/WIUBf3ZZaBGu2ee6Y8lU/app-connections/app-store" %}
[App Store](https://app.gitbook.com/s/WIUBf3ZZaBGu2ee6Y8lU/app-connections/app-store)
{% endcontent-ref %}

🎉 **Congratulations!** You have successfully linked your LND node via Alby Hub to the Alby Browser Extension.
