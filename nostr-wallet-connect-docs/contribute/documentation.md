# Documentation

## Improve these docs

Found a typo, missing example, or unclear explanation? Submit a pull request to the [getAlby/docs repository on GitHub](https://github.com/getAlby/docs). The NWC documentation lives in `nostr-wallet-connect-docs/`.

To suggest an improvement without editing the docs yourself, [open an issue](https://github.com/getAlby/docs/issues).
